# Lifedash workflow studies

Local, fictional-data design prototypes. Not the working app, not a new default, not deployed. Checkboxes, navigation and capture demonstrate interface behavior in a separate preview only. Nothing reads or writes the user's data or sync settings.

## Directions

1. Daily cockpit: one useful daily queue, scheduled items alongside it, habits and journal visible without competing with the next action. Recommended for daily use.
2. Week studio: calendar-first planning with an unscheduled tray. Better for deliberate weekly planning, less calm for quick daily checks.
3. Life areas: project/area-first overview. Better for reviewing the whole life dashboard, slower to find the next task.

These vary information hierarchy and workflow, not only color. All use the same fictional task inventory. Final selection requires John's review.
