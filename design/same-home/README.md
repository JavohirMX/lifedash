# Same-Home layout studies

These replace the earlier misleading cross-page comparison. All three show Home, with identical fictional data, actions, navigation destinations, typeface and palette. They differ in information hierarchy, density and responsive arrangement. Themes are not being compared. No layout is approved for implementation.

1. Focus + support: task-first split layout, supporting life modules in a second column.
2. Day briefing: low-chrome continuous day flow with a slim supporting rail.
3. Whole-life overview: balanced module grid, summary metrics before the work list.

Every version includes focus, three open unscheduled tasks, two scheduled tasks, two habits, two goals, one journal highlight, two upcoming tasks, the same status metrics and quick capture. Checkbox states are temporary. Buttons show a prototype notice instead of impersonating live navigation. No new feature or data model is implied.
