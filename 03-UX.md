# LifeDash — User Experience & Visual Design

**Status:** Draft | **Owner:** Javohir | **Last updated:** 2026-07-19

---

## 1. Design Philosophy

> The dashboard is ambient, not demanding. It informs without asking for attention.

- **Glanceable:** Every section communicates in under 1 second
- **Hierarchical:** What matters most (time, prayer) is biggest
- **Progressive disclosure:** Core info at a glance, detail on closer look
- **Passive:** No interactions, no clickable elements, no scrolling
- **Time-aware:** What you see depends on when you look

## 3. Typography

- **Font:** Inter (sans-serif) — loaded from Google Fonts or system
- **Base size:** 16px (TV at ~2-3m viewing distance)

| Element | Size | Weight | Example |
|---------|------|--------|---------|
| Time (HH:MM) | 6rem (96px) | Light 300 | **14:30** |
| Date | 1.5rem (24px) | Medium 500 | Tuesday, July 19 |
| Prayer countdown | 2.5rem (40px) | Bold 700 | Asr in 60 min |
| Section heading | 1rem (16px) | Semi-bold 600 | TODAY'S HABITS |
| Habit label | 1.25rem (20px) | Regular 400 | 6 AM Wake-Up |
| Progress numbers | 3rem (48px) | Bold 700 | 3/5 |

## 5. Time-of-Day Modes

### Morning Mode (Fajr — 8:00 AM)
- **Purpose:** Set the day's intention
- **Prominent:** Today's habits list, prayer schedule for the day, top todo
- **De-emphasised:** Books, highlights
- **Tone:** Energising — full brightness, cool blue primary

### Day Mode (8:00 AM — 8:00 PM)
- **Purpose:** Track progress, stay on schedule
- **Prominent:** Prayer countdown, habit completion, next task
- **Full normal layout** as shown in §4
- **Tone:** Neutral — standard palette

### Evening Mode (8:00 — 9:00 PM)
- **Purpose:** Reflection, journal trigger
- **Prominent:** Today's highlight / memorable moment, "What was your today?"
- **De-emphasised:** Habits (already recorded), todos
- **Tone:** Warm — amber accent, slightly dimmer

### Night Mode (9:00 PM — Fajr)
- **Purpose:** Minimal ambient clock
- **Content:** Large clock, next Fajr countdown, dimmed
- **Brightness:** 30% of daytime level (or CSS dark filter)
- **Animation:** Slow breathing pulse on clock digits
- **No:** Habits, todos, books — nothing demanding attention

## 6. Visual Elements

| Element | Behaviour |
|---------|-----------|
| **Checkbox icons** | Filled green (done), outline grey (pending), red (missed) |
| **Prayer bar** | Dots in a row: green=done, grey=pending, red=missed |
| **Habit progress bar** | Horizontal fill bar with fraction label |
| **Streak flame** | 🔥 emoji with count, visible only when ≥3 days |
| **Book progress** | Thin progress bar below book title |
| **Todo** | Single line, truncated if too long, with urgency indicator |
| **Highlight** | Italic, muted colour, quotation-mark style |
| **Screen saver** | After 2 min of no content change, subtle shift |

## 7. Transitions

- Mode transitions: **fade** over 1.5 seconds (CSS opacity transition)
- Data refresh: content updates in-place, no flash
- No page reloads — all data fetched via background `fetch()` + DOM update
